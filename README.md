# صفحة رسوم نشر الإعلان — سوق الرياض

صفحة هبوط عربية رسمية لقياس استعداد أعضاء مجموعة سوق الرياض للدفع مقابل رسوم نشر الإعلان. HTML/CSS/JS خام بدون خادم، متجاوبة، جاهزة للنشر على GitHub Pages.

## المزايا

- صفحة هبوط احترافية RTL تبني الثقة (الفوائد، الخصوصية، سياسة القبول/الرفض، مدة المراجعة).
- نموذج قصير: اسم فيسبوك، رابط اختياري، عنوان الإعلان، إيميل، واتساب اختياري، اختيار الباقة.
- الباقات قابلة للتعديل من `assets/js/config.js`: إعلان فردي 40 ريال / إعلان تجاري 80 ريال.
- دفع عبر **روابط PayPal المستضافة** (Payment Links) — الأموال تصل حسابك مباشرة دون خادم.
- رقم مرجعي فريد + صفحة تأكيد احترافية.
- لوحة إدارة خفيفة (رمز دخول بسيط) بحالة، بحث، موافقة/رفض يدوي، وتصدير CSV/JSON.
- صفر كلمات سر أو بطاقات أو بيانات حساسة مخزّنة.

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا بسيطًا:

```bash
npx serve .
```

## صفحة لوحة الإدارة

- الوصول: أضف `#/admin` إلى الرابط (مثال: `https://username.github.io/repo/#/admin`).
- رمز الدخول الافتراضي: `0000` — **غيّره فورًا** من `config.js` (`admin.passcode`).

## تعديل الإعدادات (ملف واحد: `assets/js/config.js`)

| المفتاح | الوصف |
|---------|-------|
| `packages` | الباقات: الاسم، الوصف، `priceSar`، `priceUsd`، `popular` |
| `paypal.mode` | `LINKS` (روابط الدفع — موصى به) / `SANDBOX` (أزرار SDK تجريبية) / `MOCK` (محاكاة) |
| `paypal.links.single` | رابط PayPal لرسوم الإعلان الفردي (40 ر.س = 10.67 دولار) |
| `paypal.links.business` | رابط PayPal لرسوم الإعلان التجاري (80 ر.س = 21.33 دولار) |
| `policy.reviewHours` | مدة المراجعة المعروضة |
| `policy.privacy` / `policy.acceptance` | بنود الخصوصية وسياسة القبول والرفض (تُعرض تلقائيًا) |
| `policy.guaranteeNote` | رسالة "الدفع لا يضمن النشر" |
| `admin.passcode` | رمز لوحة الإدارة |
| `brand` / `tagline` | اسم الجروب وشعار الصفحة |

**إضافة باقة:** أضف عنصرًا داخل `packages` وأضف رابطه في `paypal.links` — وسيظهر في النموذج تلقائيًا.

## كيف يعمل الدفع (وضع LINKS)

1. يملأ العضو النموذج ويختار الباقة.
2. يضغط «المتابعة إلى الدفع عبر PayPal».
3. يُنقل إلى صفحة الدفع المستضافة في PayPal وتُحجز الأموال في حساب الجروب مباشرة.
4. عند عودته تظهر صفحة التأكيد برقم معرّف فريد، ويظهر الطلب في اللوحة.
5. يتحقق المشرف من وصول الدفعة، يوافِق على اللوحة، ثم ينشر الإعلان داخل الجروب.

## إجراء الموافقة اليدوية (داخل الجروب)

1. افتح `#/admin` وابحث باسم فيسبوك أو عنوان الإعلان.
2. تأكد من وصول المبلغ في حساب PayPal.
3. اضغط "موافقة" لتنشر الإعلان، أو "رفض" وفق سياسة الجروب (الدفع لا يضمن النشر).

## إنشاء روابط الدفع في PayPal (مرة واحدة، ~5 دقائق)

1. سجل دخول في `paypal.com` بالحساب التجاري المستلم للأموال.
2. من القائمة: **Pay & Get Paid** ← **Payment Links and Buttons** ← **Payment link & QR code**.
3. أنشئ رابطين **بسعر ثابت (One set price)**:
   - «رسوم إعلان فردي — سوق الرياض» = `10.67` USD
   - «رسوم إعلان تجاري — سوق الرياض» = `21.33` USD
4. انسخ الرابطين وضعهما في `config.js` ضمن `paypal.links`.

## التحليلات والاسترداد (القرار النهائي للإنتاج)

**الزيارات الحقيقية (GoatCounter):**
1. سجّل مجاناً في `goatcounter.com` وأنشئ موقعاً ليأخذ كوداً مثل `riyadhsouq`.
2. ضع القيمة في `config.js` → `analytics.goatCounterSite: "riyadhsouq"`.
3. بعد النشر ستحصل على إحصاءات حقيقية (زيارات، صفحات، أجهزة) من كل الزوار دون أي سيرفر.

**الاسترداد:**
- الاسترداد **يدوي من حساب PayPal** (تفتح العملية وتضغط Refund فيعود المال فوراً للدافع)، ثم تسجّل في اللوحة بزر «استرداد».
- هذا هو النهج الاحترافي لهذا الحجم؛ لا يتطلب سيرفراً ولا يتكبد تكلفة.

## حدود النسخة الحالية (مقصودة)

- الطلبات محفوظة في `localStorage` للمتصفح نفسه؛ لفحصها من جهاز آخر صدّر CSV/JSON (الواجهة معزولة عبر `assets/js/storage.js`).
- التحقق من وصول الدفعة يدوي (لا يوجد سيرفر يتثبّت تلقائيًا) — لأن الموقع مستضاف على GitHub Pages الثابت.
- هذه ليست قناة مراسلة؛ بيانات النموذج لإتمام المراجعة فقط.

## النشر على GitHub Pages

1. أنشئ مستودعًا وارفع محتويات هذا المجلد.
2. من إعدادات المستودع → Pages → Source: `main` → `/ (root)` → حفظ.
3. عدّل `config.js` (الرابط، الرمز، النصوص) ثم ادفع.
4. الصفحة متاحة في: `https://<username>.github.io/<repo>/`.

> ملاحظة: التطبيق يستخدم Hash Routing (`#/`)، فلا يحتاج أي إعداد مسارات إضافي بغض النظر عن المسار الفرعي للمستودع.
